Access Notes

Designed for local and same-LAN use.
  • Run the service on the host computer, then open the shown origin in any browser on the same LAN.
  • EDFA state is command-tracked because the current protocol does not expose a readback query.
  • PSU channel state is refreshed from the instrument after successful commands.
  • Laser lock status is parsed from four dedicated Telnet sessions; no files on the laser controller are modified.
  • All device configuration and schedules are saved in the local JSON state file.
