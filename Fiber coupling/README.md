# Single-Mode Fiber Coupling Calculator

一个带 Tkinter 图形界面的单模光纤耦合效率辅助计算程序。默认激光波长为 `780.24 nm`，界面默认语言为英文，可通过顶部按钮切换为法语或中文。

## 运行

```bash
python3 fiber_coupling_calculator.py
```

## 功能

- 计算单模光纤与高斯光束的耦合效率。
- 考虑模式尺寸失配、波前曲率失配、横向偏移和角度失配。
- 根据准直光束半径和透镜焦距估算聚焦束腰。
- 按目标束腰反推建议焦距或建议准直光束半径。
- 用阶跃光纤 V 数和 Marcuse 近似估算模场半径，并提示单模条件。
- 支持英文、法语、中文三种界面语言切换。

## 主要模型

- 光纤基模近似为高斯 LP01 模式，模场半径取 `MFD/2`。
- 端面重叠效率采用归一化高斯场重叠积分。
- 透镜聚焦估算采用 `w0 = M^2 lambda f / (pi win)`。
- 阶跃光纤单模判据为 `V < 2.405`。

这些公式适用于实验设计和参数扫描的近似评估。高 NA 光纤、强像差透镜、端面反射、偏振相关损耗和非高斯光束需要更详细的电磁场或实测校准模型。
