Quick guide

Set, then apply

Edit a channel and choose Apply. Each output has its own On and Off buttons. Applying changes updates a running signal without switching its output on or off.

Amplitude & modulation

All levels assume a 50 Ω load and zero DC offset. Vrms and dBm are equivalent unmodulated sine levels, converted to the instrument's Vpp setting. They are not a measurement of the modulated signal.

Hardware status

Refresh verifies the real instrument identity, error registers and power-cycle flag. This model does not expose individual channel settings for readback, so unknown values stay blank. Values shown after Apply are the last commands accepted by the instrument.

Independent phase

Phase sets each channel's waveform phase offset. Different carrier frequencies do not maintain a fixed phase difference. This controller does not send a phase-align or synchronized-start command.

Disconnecting or closing this app does not switch off hardware outputs. Use each channel's Off button before disconnecting when needed.
