# MIGA21 / MIGA22 — 横向温度引起的差分 Baseline 表观相位噪声 GUI


界面右上角可选择“中文”或“English”，切换会立即更新界面、结果和图表，不会改变输入或重新计算。默认使用中文；语言设置不会写入配置文件，已有配置仍然兼容。导出的 JSON/CSV 字段采用固定英文键名，便于程序读取。
本项目是可直接在 Windows / macOS / Linux 桌面运行的 **Tkinter Python 图形界面**。
它采用我们推导过的共振两动量态 Bragg 参考模型，并支持两台原子源独立设置：

- 第一次/第三次 `π/2` 分束脉冲**整团原子平均转移效率**（界面中按百分数输入，例如 20）；
- `π` 镜面脉冲平均转移效率（例如 40）；
- 横向平均温度 `T`（μK）；
- 温度 shot-to-shot Allan deviation `σ_T`（μK）；
- 实测条纹平均布居 `B_measured` 与绝对振幅 `A_measured`（按百分数输入）；
- 分束和镜面脉冲的 Rabi 振荡分支，可以要求脉冲面积超过 `π/2` 或进入下一个 Rabi 分支；
- 可选的初始原子云大小、光束腰、空间接受范围、原子云中心位置等。

## 1. 安装与启动

Python 版本建议 **3.10+**。

在项目目录执行：

```bash
python -m pip install -r requirements.txt
python miga_temperature_gui.py
```

两个功能使用独立窗口：

- **温度噪声**：Windows 双击 `launch_temperature_windows.bat`，或运行 `python miga_temperature_gui.py`；macOS/Linux 运行 `bash launch_temperature_unix.sh`。
- **发射速度 / 位置噪声**：Windows 双击 `launch_velocity_windows.bat`，或运行 `python miga_launch_gui.py`；macOS/Linux 运行 `bash launch_velocity_unix.sh`。

原来的 `launch_windows.bat` 和 `launch_unix.sh` 保留为温度界面入口。两个程序共享计算核心和配置格式，但分别打开、计算和导出。

**注意：** `tkinter` 在 Windows/macOS 常见 Python 安装中通常自带；Linux 如未安装，则需要系统包 `python3-tk`，而不是单纯 pip 安装。

## 2. 点击 Calculate 之后计算什么？

1. 采用给定平均温度 `T_0`，构建二维横向高斯原子分布，计算整团原子的转移概率。
2. 为每台原子源分别求解峰值分束脉冲面积 `θ_s` 和镜面面积 `θ_m`，令**模型的平均单脉冲效率**对应你输入的实验值。
3. **只做一次标称温度校准**。然后冻结 `θ_s,θ_m`，计算 `B(T_0 + ΔT)` 和 `B(T_0 - ΔT)`。
4. 利用 `K_B = [B(T_0+ΔT)-B(T_0-ΔT)]/(2ΔT)` 得到温度灵敏度（每 μK）。
5. 计算单源 baseline 人口 Allan：`σ_B ≈ |K_B| σ_T`。
6. 使用各自**实测条纹振幅**：`σ_φ,apparent = σ_B/A_measured`（rad）。
7. 假设两台原子源温度波动相互独立，差分：`σ_diff = sqrt(σ_22^2 + σ_21^2)`。

三个脉冲的局部转移概率为

```
a = sin²(θ_s e^{-2r_1²/w²}/2)
b = sin²(θ_m e^{-2r_2²/w²}/2)
c = sin²(θ_s e^{-2r_3²/w²}/2)
```

只保留两条闭合的 Mach–Zehnder 路径相干叠加时，单原子条纹基线和振幅为

```
B_atom = b + (a + c - 2ac)(1 - 2b)
A_atom = 2b sqrt[a(1-a)c(1-c)]
```

`Radial (fast, centered)` 为默认方法，假设束心与云心重合、三脉冲采样的横向坐标近似相同，利用一维 Gauss–Laguerre 积分，稳定快速。

`4D trajectory (slower)` 使用原子初始 `(x_0,y_0,v_x,v_y)` 的 4D Gaussian 分布，通过 Gauss–Hermite 积分跟踪 3 个不同脉冲中心的横向位置，支持云心偏移和 apex 两侧的重力高度变化。**此模式的高阶振荡积分可能收敛缓慢**，建议对比不同 quadrature order 的结果，不要盲信 10 节点的计算值。默认预算建议用径向模式估算。

## 3. 默认结果

采用输入：

| 输入 | MIGA22 | MIGA21 |
|---|---:|---:|
| 平均温度 | 2.599 μK | 1.869 μK |
| 温度 Allan | 0.151 μK | 0.109 μK |
| 平均 π/2 转移效率 | 20% | 20% |
| 平均 π 转移效率 | 40% | 40% |
| 实测 B | 0.2905 | 0.4165 |
| 实测 A | 0.175 | 0.210 |

径向模式下，初始化 RMS 大小 0.25 mm，束腰 12 mm，t=430.5 ms，得到：

| 模型输出 | MIGA22 | MIGA21 |
|---|---:|---:|
| 中心分束面积 `θ_s / π` | 0.583 | 0.513 |
| 中心镜面面积 `θ_m / π` | 0.939 | 0.796 |
| 模型 B | 0.32038 | 0.35099 |
| 模型 A | 0.16244 | 0.15872 |
| `dB/dT` (每 μK) | -0.06713 | -0.08843 |
| 相位 Allan | **57.92 mrad** | **45.90 mrad** |

**独立原子源差分：73.90 mrad**。

这是明确假设下可复现的估算。**模型的 B/A 不完全符合实测**，特别是 MIGA21 的 `B_measured=0.4165`、`A_measured=0.210`。因此 **73.90 mrad 不是实验确认的差分温度噪声预算**。

另外，MIGA21 选择的默认分束中心脉冲面积 `θ_s≈0.513π`，比理想 `π/2` 稍大，符合你指出的过旋转方向。该数值仍然是简化模型的条件性拟合。

## 4. GUI 各项输入的重要含义

- `B_measured`：**只用于比较模型与实验，并不会强行拟合**。模型算出的 B 会独立显示。
- `A_measured`：**用于把布居 Allan 除以实验相位斜率**。GUI 同时显示模型的 A，便于一致性检查。
- `Rabi branch`：由于 `sin²(θ/2)` 不是单调函数，可能有多个脉冲面积符合相同的转移效率。不同分支可能给出不同 `K_B`；若某分支不支持目标效率，程序会报错而不是偷换成另一个分支。
- `Detection acceptance width`：有效空间权重的假设，不等于已知的实际探测面积。`0` 不施加额外权重。
- `center x/y` 和 `include ballistic shift`：只能在 4D 模式使用，径向模型不支持非中心情景，会给出清晰的错误提示。
- 每源分束/镜面中心面积分别校准，**不强制两台原子源使用相同的光束中心 Rabi 频率**。这是便于用户指定不同实测效率的经验建模做法，不保证满足一个完整共用光场的所有物理约束。

## 5. 使用导出功能

- `保存配置` / `读取配置`：保存和打开所有参数，JSON 格式。
- `导出结果 JSON`：保存校准参数、噪声灵敏度、模型与实测偏差、温度扫描以及告警信息。
- `导出扫描 CSV`：可用于 Excel / Origin / Python 绘图。
- `导出图片 PNG`：保存当前温度曲线。

`sample_results.json`、`default_scan.csv` 和 `default_plot.png` 是随包提供的默认计算实例。

## 6. 重要物理限制

此程序**不是**完整 Blackman quasi-Bragg 仿真：

- 不包含轴向 90 nK 等效宽度造成的 Doppler 失谐；
- 不包含 `±3ℏk` 等更高动量态；
- 不计算实际 diffraction phase；
- 不包含真实空间波包重叠、Raman 读出权重、不同 `mF` 组分或精确探测归一化；
- 预测的 B/A 与实测不一致时，输出 `K_B` 属于模型情景值；
- 若温度噪声大到线性近似失效，应采用非线性传播计算。

因此可用它做初步噪声预算、分支敏感性、参数扫描和数量级评估；不应在论文中将其结果写为直接实测的噪声贡献。

## 8. 发射速度 / 位置噪声（新增）

独立的发射速度 / 位置噪声窗口使用左侧的光束腰、脉冲间隔、初始云宽、两源温度、单脉冲效率、Rabi 分支及实测 B/A；右侧分别输入到达时间、Allan、竖直偏移和有效曲率。发射模型始终使用四维相关高斯轨迹积分，不受左侧温度模型的径向/4D 选项影响。旧配置没有 launch 字段时，发射页使用默认输入；保存配置时一并保存发射输入。

默认实验输入为检测高度 0.275 m、g=9.81 m/s²，MIGA22 为 0.7996 s / 103.8 μs，MIGA21 为 0.8000 s / 115.0 μs。计算**假设检测时间变化只来自发射速度变化**，不包含发射位置、检测阈值或时钟抖动。位置零点是发射点，检测为下降经过检测高度。各 Allan 输入须对应相同平均时间。

中间脉冲时间输入 0 表示每台源使用自身标称最高点，正数表示使用同一实验室时间（从发射算起，单位 ms）；计算速度扰动时三脉冲时间固定。竖直偏移定义为标称中间脉冲云心高度减光束中心高度：正数表示云心在光束中心上方；发射模型不使用温度模型的 x 偏移，y 偏移仍沿用。默认 0 mm 仅是情景假设。有效接受宽度沿用左侧输入：0 为无选择；非零时用固定在标称中间云心、随原子位置变化的实验室高斯权重，仅为近似，非检测面精确模型。

每台源在标称条件下校准一次峰值分束与镜面脉冲面积；所有速度及静态偏移扫描都固定这组面积和光束中心。偏移扫描同时移动束心相对标称云心的位置，扫描本身不重新校准。GUI 给出 B(v)、偏移扫描、曲率扫描与差分曲线；曲线中的差分偏移/曲率扫描表示两源取同一个横轴值，按源间独立假设合成。CSV 包含单源及差分扫描数据；JSON 还包含模型、输入、单位、敏感度、校准值、诊断和假设。PNG 保存发射窗口图表。

发射界面将基线斜率转换为带符号相位响应：`K_baseline = -K_B/(s A_measured)`，其中 `s=+1/-1` 由固定读出工作点的条纹斜率决定。可选波前使用 `k_eff=4π/λ` 的**有效双光子二次相位**和平均云心轨迹；曲率输入支持正负号，0 表示平面波。默认 200 m 只是示例，不是原子处实测曲率。波前计算是独立的云心近似，并非在原子系综上对空间相位作相干平均的完整波前模型，更不是 quasi-Bragg diffraction phase。两项由同一速度波动驱动，按 `K_total=K_baseline+K_wavefront` 带符号相加，再计算 Allan；两源按独立假设平方和。不要将该项与温度噪声直接平方和，除非相关性已知。

积分使用标称中间脉冲位置和条件热速度的相关变量进行四维 Gauss–Hermite 积分；主位置和剩余速度的阶数分别为 `n` 和 `min(10,max(4,ceil(n/8)))`。默认主阶数 48，对照阶数 64，两个阶数分别在标称点校准。程序在标称偏移处比较 B、A 和速度导数，也比较 h 与 h/2；不满足阈值时明确告警，需提高阶数复核。偏移扫描的每个点没有单独做阶数对比，应在关注的偏移处重新运行并检查收敛。程序同时检查一个速度 Allan 范围内的基线曲线弯曲；如出现非线性告警，一阶传播可能漏计噪声。高 Rabi 分支、较小光束或大偏移可能需要更高精度。各项是依赖模型和假设的情景计算，不是已验证的 MIGA 噪声预算。

运行 `python test_launch.py` 检查到达时间换算、两阶积分和微分收敛、固定脉冲面积、平面波和零抖动极限、同源带符号合成以及独立源差分。`sample_launch_scenario.json` 是启用 200 m 示例曲率的计算结果，包含完整输入与告警，不代表实测。

**波前开关与扫描图：**未勾选“启用二次波前”时，结果表显示“未启用”，总响应不包含波前项；曲率图始终显示假设启用波前时的情景扫描。修改开关后须点击“计算发射噪声”，结果表才会更新。JSON 中关闭波前时该项仍以数值 0 表示，并由 `settings.wavefront_enabled` 标识开关状态。
